# 🚀 Sobre el Proyecto

Este repositorio es una **extensa colección de pequeños proyectos, ejercicios y apuntes** que cubren una gran variedad de temas de programación. Funciona como un sandbox y un registro de aprendizaje, abarcando desde la manipulación del DOM con JavaScript puro hasta la creación de servidores backend con Node.js y la exploración de librerías de creative coding e inteligencia artificial.

✨ **Características principales:**

*   💻 **Ejercicios de DOM**: Múltiples ejemplos prácticos de manipulación del **`Document Object Model`** usando JavaScript Vanilla, desde la captura de eventos en inputs hasta la creación dinámica de elementos.
*   🌐 **APIs con Node.js**: Varios microservicios construidos con **`Node.js`** y **`Express`**, que sirven datos desde una base de datos y exponen endpoints RESTful.
*   🗃️ **Persistencia con SQLite**: Proyectos que integran bases de datos **`SQLite`** para almacenar y gestionar información de forma ligera y eficiente.
*   🎨 **Creative Coding con p5.js**: Sketches y juegos interactivos que exploran las capacidades de la librería **`p5.js`** para crear experiencias visuales en el navegador.
*   🐍 **Scripts de Python**: Ejemplos que exploran la interacción con modelos de **`Hugging Face`** y el manejo de bases de datos.
*   📝 **Cheatsheets y Apuntes**: Una colección de guías rápidas y notas en formato Markdown sobre Git, SQL, servidores, asincronía y más.

# 🧠 Contexto del Proyecto

Este repositorio ha sido desarrollado como parte del primer año del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (1º DAM)**. Sirve como un diario de código, recopilando los ejercicios realizados en clase, proyectos personales para reforzar conocimientos y una base de apuntes para consulta rápida. La diversidad de carpetas y tecnologías refleja el amplio temario cubierto durante el curso.

# 📂 Estructura del Proyecto

El repositorio está organizado en múltiples carpetas, cada una representando un ejercicio, un pequeño proyecto o una categoría de apuntes.

```bash
.
├── DOM/             # Ejercicios de manipulación del DOM
├── EXAMEN/          # Ejemplos prácticos tipo examen
├── T_Juego/         # Juego tipo Cookie Clicker con p5.js y backend
├── cheatsheets/     # Apuntes y guías rápidas en Markdown
├── frutas/          # Ejemplo de API REST con Node.js y SQLite
├── http_servidor_basico/ # Servidor Express básico
├── huggingface/     # Scripts de Python con la librería Hugging Face
├── intro_sqlite/    # Introducción a SQLite con Python y Shell
├── juego_p5/        # Juego con p5.js y backend
├── p5/              # Sketches básicos con p5.js
├── parking/         # API para gestión de parking con WebSockets
├── users-htmx/      # CRUD de usuarios con Express y HTMX
└── ... y muchos más archivos y ejercicios
```

# 🚀 Cómo Utilizar el Proyecto

Dado que este repositorio contiene múltiples proyectos independientes, los pasos para ejecutar cada uno pueden variar. A continuación se muestran las instrucciones generales para un proyecto típico de `Node.js` (por ejemplo, `frutas` o `parking`).

1.  **Clona el repositorio:**
    ```bash
    git clone https://github.com/evagr11/codebase.git
    cd codebase
    ```

2.  **Navega a la carpeta de un proyecto específico:**
    ```bash
    # Ejemplo para el proyecto 'frutas'
    cd frutas
    ```

3.  **Instala las dependencias:**
    Se utiliza `npm` para gestionar los paquetes.
    ```bash
    npm install
    ```

4.  **Inicia el servidor:**
    La mayoría de los proyectos usan `npm start` para arrancar el servidor.
    ```bash
    npm start
    ```
    El servidor se ejecutará, por lo general, en `http://localhost:3000`.

> **Nota:** Algunos proyectos son simplemente archivos `.html` que puedes abrir directamente en tu navegador. Otros son scripts `.py` que se ejecutan con `python nombre_del_script.py`. Revisa el contenido de cada carpeta para entender su funcionamiento.
